설정

아무것도 넣지 않아도 누구나 네이버 지도를 씁니다. 키는 길안내 서버에서 자동으로 받아 오고, 서버에 잠깐 닿지 않으면 마지막으로 받은 키를 씁니다. 다른 키를 시험할 때만 넣으세요. (현재 주소 )

단속 카메라 -대 · 기준일 - (경찰청 공공데이터)

자동이면 지금 위치의 해 지는 시각에 맞춰 지도를 어둡게 바꿉니다. 지도 위 달·해 버튼으로도 자동 → 항상 어둡게 → 항상 밝게 순서로 바꿀 수 있습니다.

주행 중에는 차가 화면 아래쪽에 오고 앞쪽 길이 더 넓게 보입니다. 지도를 만지면 북쪽이 위인 평면 지도로 바뀌고, 위치 버튼을 누르거나 15초가 지나면 돌아옵니다.

경로를 벗어나면 같은 목적지를 추천 경로로 다시 찾습니다. 무료 도로를 고르셨다면 다시 찾을 때도 무료 도로로 찾습니다.

진단 모드는 실제 차에서 GPS 갱신 주기, 위치 지연, 정확도, 화면 반영 시간을 재고 주행 기록을 남깁니다. 주행 후 업로드하면 기록 번호가 나옵니다.
