# 테슬라 브라우저용 지도 클러스터

테슬라 차량 브라우저에서 여는 웹페이지 하나(`index.html`)입니다.
왼쪽은 계기판(GPS 속도, 방향, 시계, 주행 거리와 시간), 오른쪽은 네이버 지도입니다.
따로 앱을 설치하지 않고, 주소만 즐겨찾기해서 씁니다.

- 네이버 키가 없거나 인증에 실패하면 **테스트 지도(OpenStreetMap)** 로 자동 전환됩니다.
- `?demo=1`을 붙이면 차 없이도 서울 시청 주변을 도는 **데모 주행**으로 화면을 확인할 수 있습니다.

## 1. 내 PC에서 먼저 보기

이 폴더에서 아래 명령을 실행합니다.

```bash
python -m http.server 8765
```

브라우저에서 `http://localhost:8765/?demo=1` 을 엽니다.

## 2. 네이버 지도 키 받기 (NAVER Cloud Platform)

1. ncloud.com 에 가입합니다. 서비스를 쓰려면 결제수단 등록을 요구할 수 있습니다. Maps에는 무료 사용량이 있으니 요금은 콘솔에서 확인하세요.
2. 콘솔 → Services → **Maps** → **Application 등록**
3. API 선택에서 **Dynamic Map** 을 체크합니다.
4. **Web 서비스 URL** 에 이 페이지를 열 주소를 등록합니다.
   - PC 테스트용: `http://localhost:8765`
   - 실제 사용 주소: 예) `https://내아이디.github.io`
5. 인증 정보의 **Client ID** 를 복사합니다.
6. 페이지 오른쪽 위 설정 버튼에 붙여 넣거나, 처음 한 번만 `주소?key=ClientID` 로 엽니다.
   - 키는 그 브라우저에 저장되고, 주소창에서는 바로 지워집니다.

> 예전 예제의 `ncpClientId` 파라미터는 `ncpKeyId` 로 바뀌었습니다. 이 페이지는 `ncpKeyId` 를 씁니다.

## 3. 인터넷에 올리기 (GitHub Pages, 무료)

차 브라우저에서 열려면 HTTPS 주소가 필요합니다. 위치 권한이 HTTPS에서만 동작하기 때문입니다.

1. GitHub에 새 저장소(예: `tesla-naver-cluster`)를 만들고 `index.html` 을 올립니다.
2. 저장소 Settings → Pages → Branch를 `main` / `(root)` 로 저장합니다.
3. 잠시 뒤 `https://내아이디.github.io/tesla-naver-cluster/` 로 열립니다.
4. NCP의 Web 서비스 URL에 `https://내아이디.github.io` 를 추가합니다.

## 4. 테슬라에서 쓰기

1. 차량 브라우저에서 위 주소를 열고, **위치 권한을 허용**합니다.
2. 즐겨찾기에 추가하고, 브라우저 아이콘을 하단 독에 고정해 두면 두 번 터치로 열립니다.
3. 주소창 없이 전체화면으로 쓰려면, **주차 상태**에서 극장 모드 → YouTube → 주소창에 아래처럼 엽니다.
   ```
   https://www.youtube.com/redirect?q=https://내아이디.github.io/tesla-naver-cluster/
   ```
   테슬라 업데이트로 이 방법이 막힐 수 있습니다.

## 버튼

| 버튼 | 기능 |
| --- | --- |
| 달/해 | 야간 지도 켜기/끄기 (지도 색 반전) |
| 네모 | 전체화면 (브라우저가 허용할 때만 보임) |
| 설정 | 네이버 Client ID, 데모 주행, 주행 기록 초기화 |
| + / − | 확대 / 축소 |
| 조준점 | 내 위치 따라가기. 지도를 손으로 움직이면 초록색으로 바뀌고, 15초 뒤 자동으로 돌아옵니다 |

## 한계

- **속도는 GPS 기준**입니다. 차 속도계와 조금 다를 수 있고, 터널이나 지하에서는 끊깁니다. 차량 데이터(배터리, 기어)는 웹페이지에서 읽을 수 없습니다.
- **길안내(턴바이턴)는 없습니다.** 지금은 지도와 내 위치만 보여 줍니다. 경로를 그리려면 NCP Directions API와, 비밀 키를 숨길 작은 서버가 필요합니다.
- **주행 중 브라우저 사용**이 테슬라 정책이나 지역에 따라 제한될 수 있습니다. 실제 차에서 확인이 필요합니다.
- 차량 브라우저가 위치 권한을 어떻게 주는지(정확도, 갱신 주기)는 차에서 직접 확인해야 합니다.
