# 테슬라 브라우저용 지도 클러스터

테슬라 차량 브라우저에서 여는 웹페이지입니다. 앱 설치 없이 주소를 즐겨찾기해서 씁니다.

- 주소: https://bravecheeze.github.io/tesla-naver-cluster/
- 왼쪽 계기판: GPS 속도, 제한속도 표지, 현재 도로 이름, 방향, 단속 카메라 경고, 구간단속 평균속도, 주행 거리와 시간
- 오른쪽 지도: 네이버 지도, 주행 중 확대 화면(진행 방향이 위), 목적지 검색, 경로 안내, 음성 안내
- 네이버 키가 없거나 인증에 실패하면 테스트 지도(OpenStreetMap)로 자동 전환됩니다.
- `?demo=1`을 붙이면 차 없이 데모 주행으로 화면을 확인할 수 있습니다. 경로를 띄운 상태에서 데모를 시작하면 그 경로를 따라 달립니다.

## 구성

| 파일 | 내용 |
| --- | --- |
| `index.html` | 화면 구조와 스타일 |
| `app.js` | 계기판, 지도, 단속 카메라, 길안내, 음성, 진단 |
| `data/cameras.json` | 경찰청 전국무인교통단속카메라표준데이터 (v2: 과속·신호·구간 카메라, 도로명·도로 종류·방향 포함. 15m 안에 겹친 같은 카메라는 하나로 합침) |
| `worker/worker.js` | Cloudflare Worker. 네이버 API 비밀키를 숨기고 경로·주소·장소 검색·도로명·진단 기록을 중계 |
| `test/` | 브라우저에서 돌리는 자동 시나리오 테스트 |
| `tools/build_bumps.py` | 전국 과속방지턱 CSV → `data/bumps.json` (중복 합치기·차이 부호화) |
| `tools/build_hipass.py` | 한국도로공사 영업소별 하이패스차로 운영현황 CSV → `data/hipass.json` (영업소·방향별 승용차 하이패스 차로 번호) |
| `tools/fetch_signs.py` | 전국도로안전표지표준데이터 오픈API에서 주의표지만 전부 받기 (인증키는 환경변수 `DATA_GO_KR_KEY`로만) |
| `tools/build_signs.py` | 도로안전표지 CSV 또는 위 JSON → `data/signs.json` (주의표지 10종, 중복 합치기·차이 부호화) |
| `tools/build_tunnels.py` | OpenStreetMap 터널 도로(Overpass JSON) → `data/tunnels.json` (지하차도 빼기·단순화·차이 부호화) |
| `tools/build_cams.py` | 원본 카메라 CSV → `data/cameras.json` 변환 (직접 확인한 데이터 보정 `FIXES` 포함) |

## 1. 네이버 지도 키 (NAVER Cloud Platform)

1. 콘솔 → Maps → Application에서 Dynamic Map, Directions 5, Geocoding, Reverse Geocoding을 켭니다.
2. Web 서비스 URL에 `https://bravecheeze.github.io`와 `http://localhost:8765`를 등록합니다.
3. **Client ID**는 페이지 설정 버튼에 한 번 넣습니다. 차 브라우저에 저장됩니다.
4. **Client Secret**은 페이지에 넣지 않고 아래 Cloudflare Worker에만 넣습니다.

무료 사용량(월): Dynamic Map 600만, Geocoding·Reverse Geocoding 각 300만, Directions 5는 6만 건입니다.

## 2. 길안내 서버 (Cloudflare Worker `tesla-nav`)

- 주소: https://tesla-nav.cy6789.workers.dev (`/health`로 상태 확인)
- Worker → Settings → Variables and Secrets에 **Secret**으로 넣습니다.
  - `NCP_KEY_ID`: 네이버 클라우드 Client ID
  - `NCP_KEY`: 네이버 클라우드 Client Secret
  - (선택) `NAVER_SEARCH_ID`, `NAVER_SEARCH_SECRET`: 네이버 개발자센터 검색 API. 넣으면 "스타벅스 강남" 같은 장소 이름 검색이 됩니다. 없으면 주소 검색만 됩니다.
- Bindings: KV namespace `tesla-nav-logs`를 변수 `LOGS`로 연결했습니다. 진단 기록을 30일 동안 보관합니다.
- 허용된 페이지 주소(`bravecheeze.github.io`, `localhost:8765`)에서 오는 요청만 받습니다.
- 코드를 고치면 `worker/worker.js` 내용을 Cloudflare 편집기에 붙여 넣고 Deploy합니다.

## 3. 테슬라에서 쓰기

1. 차량 브라우저에서 주소를 열고 **위치 권한을 허용**합니다.
2. 화면을 한 번 터치해야 소리가 켜집니다. 브라우저 정책 때문입니다. 설정 → 소리 테스트로 확인할 수 있습니다.
3. 즐겨찾기에 추가합니다. 주소창 없이 쓰려면 주차 중 극장 모드 → YouTube에서 아래 주소를 엽니다.
   ```
   https://www.youtube.com/redirect?q=https://bravecheeze.github.io/tesla-naver-cluster/
   ```

## 테슬라 모드

- 2026-11-14 부터 테슬라 모드가 유일한 화면입니다(예전 왼쪽 계기판 화면과 설정의 "테슬라 모드" 스위치는 없앴습니다. 어느 브라우저에서 열어도 이 화면). 속도는 차 화면에 이미 나오므로 왼쪽 계기판 칸을 없애고 지도를 화면 가득 씁니다. 나머지는 배경 없이 글자로 지도 위에 띄웁니다:
  - 오른쪽 위: 시계·날짜·날씨 / 오른쪽 가운데: 얇은 경로 막대 (모두 화면 테두리에서 띄움)
  - 길안내 패널 맨 위에 목적지(초록 목적지 아이콘 + 이름, 경유지가 있으면 오른쪽에 작게, 밑에 초록 그라데이션 밑줄), 그 밑에 몇 km 뒤 어디로 도는지, 그다음 칸(이번 회전을 하고 나서 무엇이 얼마 뒤에: 회전이면 네이버 지도처럼 그 회전 아이콘(초록) + 거리만 '↰ 1.2km', 목적지면 연한 빨강 바탕에 빨간 핀 + '20m'('도착' 글자 없이), 경유지면 주황 핀. 아래 회색 요약 줄과 헷갈리지 않게 흰 바탕), 맨 밑 남은 거리·시간·도착
  - 왼쪽 위: 길안내 패널 → 그 바로 밑에 단속 경고(배경 없이) → 길안내 패널 폭의 '내 속도 · 제한' 띠(넘으면 빨갛게 깜박) → 다음 단속(글자 없이 제한속도 표지 + 거리)
  - 가운데 아래: 지금 위치(달리는 도로 이름 + 시·군·읍면, 역지오코딩)를 어두운 띠로. **누르면 버튼이 올라옵니다**:
    길안내 중이면 **경로 비교**(안내를 멈추지 않고 '지금 경로'와 추천·빠른 길·무료 도로를 비교, 고르면 바로 그 경로로, '원래 경로로'로 되돌리기) ·
    **재추천**(지금 위치에서 추천 경로로 다시) · **경유지 추가/빼기**(검색해서 고르면 목적지는 그대로 그곳을 거쳐 가는 경로로. 경유지 150m 안을 지나면 자동으로 빠지고, 재탐색·교통 갱신도 경유지를 지킴).
    길안내가 없으면 '목적지 검색'. 8초 동안 안 누르면 다시 내려갑니다
  - 왼쪽 아래: 맨 아래 주행 기록, 그 위 나침반 / 오른쪽 아래: 지도 저작권 표시 위에 GPS
  - 구간단속 중에는 경고 카드(예: 구간단속 끝 1.4km) 오른쪽 끝에 구간 평균 속도와 지킬 속도가 붙습니다
  - 글꼴은 Pretendard (페이퍼로지는 운전 중 가독성이 떨어져 되돌림)
  - 지도 위 글자(시계·날씨·주행 기록·나침반·단속 경고·다음 단속·GPS)는 흰 글자에 글자 둘레만 얇은 그림자(예전처럼 넓게 번지는 진한 그림자는 아님). 단, 주행 기록(주행 거리·시간·평균·최고 속도)만 낮에는 검정 글자에 얇은 흰 테두리(밤에는 흰 글자)
  - 단속 경고는 따로 뜨는 창이 아니라 **길안내 패널(맨 밑 '안내 종료' 줄) 밑에서 스르륵 내려오는 서랍**입니다. 패널은 그대로 있고 서랍만 그 밑으로 열리며(양옆이 패널보다 조금 안쪽), 경고가 끝나면 위로 접힙니다. 서랍 안은 맨 위 내 속도 띠 → 신호·과속 카드(또는 구간단속 카드) → 작은 보호구역 표지 순서. 길안내가 없으면 혼자 둥근 카드
  - 테슬라 브라우저를 크게 펼치면(실측 1307×747, 차 화면의 속도계가 가려짐) 왼쪽 나침반 위에 큰 속도계(+ 제한속도 표지)가 나옵니다. 보통 크기(804×638)에서는 숨김
  - 오른쪽 아래: 맨 아래 GPS, 새 버전이 있으면 그 위에 작은 '업데이트' 버튼. 지도 출처 표시(© NAVER Corp. /국토교통부 …)는 네이버 지도 이용 약관상 지울 수 없어서 왼쪽 아래 구석에 작게
  - 색과 표면은 네이버 지도 느낌: 흰 바탕(#fff)·진회색 글자(#333)·초록 강조(#03c75a), 테두리 없이 옅은 그림자. 길안내 패널은 흰 카드(초록 화살표, 아래 회색 줄, '안내 종료'는 테두리 없는 빨간 글자). 밤(어두운 지도)에는 어두운 패널(#25282d)로 자동 전환. 검색·설정·주행 기록 창도 같은 색. 안내 패널·버튼·카드·창은 아주 살짝 유리 느낌(78% 흰 바탕 + 뒤 흐림 + 위쪽 얇은 빛)
  - 터치하면 나오는 버튼은 절반 크기. 야간·전체화면·설정 버튼은 길안내 패널(없으면 검색 버튼) 바로 오른쪽에 붙어 나옵니다
- 톨게이트 안내(네이버 안내 종류 121)는 직진 화살표 대신 파란 'TG' 표지 + 도로 그림으로, 안내 문구는 통행료를 굵게 앞에 '560원 하남톨게이트'로 보여 줍니다(2026-11-14).
- 하이패스 칸(서랍 맨 밑)은 한 줄: 왼쪽 'hi-pass' 표지, 가운데 톨게이트 이름·통행료와 '하이패스 차로 이용', 오른쪽 큰 남은 거리.
- 하이패스 칸은 톨게이트가 길안내 패널의 다음 안내면 거리를 빼고(패널에 크게 나옴), 차로 번호가 있으면 'hi-pass [1][2] – [5] 번 차로'만 보여 줍니다(2026-11-14).
- 하이패스 차로 번호(2026-11-14): 한국도로공사 '영업소별 하이패스차로 운영현황'(data.go.kr 15043760, 파일데이터, 이용 제한 없음, 연 1회 갱신, 2026-06-30 기준 영업소 443곳)을 `tools/build_hipass.py` 로 `data/hipass.json`(14KB)에 담아 두고, 앱이 톨게이트 이름('하남톨게이트' → '하남')으로 바로 찾습니다(키·서버 필요 없음). 승용차가 쓸 수 있는 하이패스·다차로하이패스·하이패스+유인 겸용 차로만(화물차 전용 차로 제외). 폐쇄식 영업소는 고속도로 진입 안내(4km 안) 뒤면 입구, 출구 안내(3km 안) 뒤면 출구 차로, 안내로 모르면 같은 경로에 앞서 지난 폐쇄식 톨게이트가 있으면 출구·뒤에 또 있으면 입구. 개방식(상행·하행)은 수도권 방사형 노선에서만 '서울 쪽으로 가면 상행'(톨게이트 앞뒤 400m 진행 방향과 서울 쪽이 50° 안이면 상행, 130° 넘으면 하행. 실제 경로로 확인: 하남IC→중부 6°, 하남IC 출구 140°, 판교IC→경부 20°), 그 밖에는(순환선·지방, 애매한 방향) 양쪽 다 하이패스인 차로만 보여 줍니다(틀린 번호를 내지 않게. 예: 성남은 1·2·3번). 한국도로공사 실시간 API '영업소 하이패스 차로 개폐 현황'(data.ex.co.kr apiId 0623, Worker `/hipass` + Secret `EX_KEY`)은 자율주행 실증사업 시험 구간용이라 전주·동군산·서대전 3곳만 나와서 쓰지 않습니다. 자동 테스트 S53.
- 하이패스: 길안내 경로에 톨게이트가 있으면 2km 앞부터 이름·남은 거리·통행료를 보여 주고(테슬라 모드에서는 단속 서랍 맨 밑에 연한 파랑 칸으로, 2026-11-14) "하이패스 차로를 이용하세요"라고 알립니다. 몇 번 차로가 하이패스인지는 아래 '하이패스 차로 번호'(한국도로공사 인증키 필요).
- 테슬라 브라우저(화면 804×638, 'X11; Linux x86_64')에서는 처음부터 켜져 있습니다. 설정에서 끄면 그 값을 기억합니다.

## 야간 지도

- 기본은 **자동**: 지금 위치에서 해가 지평선 아래 2°로 내려가면(해 지고 10분쯤) 어두운 지도로, 해가 뜨면 밝은 지도로 1분 안에 바뀝니다.
- 지도 위 달·해 버튼: 자동(작은 A 표시) → 항상 어둡게 → 항상 밝게 → 자동. 설정 → 야간 지도에서도 고를 수 있습니다.
- 벡터(GL) 지도(기본)에서는 **네이버의 다크 지도**(어두운 바탕·글자·가게 아이콘, 실시간 교통 선도 다크 색)를 씁니다. 네이버 GL 스타일 안에 들어 있는 `dbasic` 지도 종류를 앱이 지도 종류로 등록해 바꿔 끼우는 방식이라 키·스타일 에디터가 필요 없습니다. 경로선·카메라·내 차 아이콘은 원래 색 그대로입니다. 다크 스타일을 못 받으면 지도만 어둡게(색은 그대로) 합니다.
- 그림(래스터) 지도일 때는 예전처럼 지도 바탕에만 색 반전과 대비 높이기를 겁니다.
- 테슬라 화면의 밤·낮과 바로 연동하는 방법은 아직 없습니다. 브라우저가 주는 화면 테마(prefers-color-scheme)를 접속 기록에 남겨 쓸 수 있는지 보는 중입니다.

## 즐겨찾기

- 검색창을 열면 맨 위에 **집 · 회사** 버튼, 그 아래 즐겨찾기와 최근 목적지가 나옵니다. 집·회사를 누르면 바로 경로를 찾습니다.
- 검색 결과·목록 옆 ☆ 를 누르고 "★ 즐겨찾기 / 집으로 / 회사로 / 빼기"를 고릅니다. 이 차 브라우저에 저장됩니다(최대 20곳).

## 주행 기록

- 화면의 주행 거리·주행 시간·평균·최고 속도는 몇 초마다 저장해 두고, 새 버전으로 바뀌면(하루 안) 그대로 이어서 셉니다. 그냥 새로고침이면 30분 안일 때만 이어서(2026-11-14 요청). 자동 테스트 S49.

- 움직이기 시작하면 주행이 시작되고, 5분 넘게 서 있으면 끝납니다. 주행마다 날짜·시간, 출발·도착(지역·도로), 목적지, 거리, 운전 시간, 평균·최고 속도를 남깁니다. 300m 안 되는 이동은 뺍니다.
- 과속 내역: 단속 카메라 600m 앞부터 지날 때까지 제한을 넘었으면(카메라마다 한 번, 가장 빨랐던 속도), 구간단속 평균이 제한을 넘었으면 그 시각·장소·제한·내 속도를 남깁니다. 일반 도로의 제한속도는 데이터가 없어 카메라·구간단속에서만 셉니다.
- 지도 위 막대그래프 버튼(위쪽 버튼 줄) → 주행 목록. 주행을 누르면 과속한 곳이 펼쳐지고, 과속한 곳을 누르면 지도에서 그 자리를 보여 줍니다.
- 이 차 브라우저에만 저장됩니다(최근 60번 주행). 새로고침하거나 새 버전으로 바뀌어도 10분 안이면 같은 주행으로 이어 씁니다. "기록 지우기"는 두 번 눌러야 지워집니다.

## 날씨

- 오른쪽 위에 날씨 아이콘(해·달·구름·이슬비·비·눈·안개·천둥번개)과 기온, 날씨, 1시간 안 비 올 확률을 보여 줍니다. 해가 지면 해 대신 달 아이콘이 나옵니다.

## 지도 조작

- 지도 위 버튼(검색·설정·확대 등)은 화면을 한 번 터치하면 3초 동안 보였다가 사라집니다. 첫 터치는 버튼을 보여 주기만 합니다. 길안내 패널·카메라 경고·소리 켜기 안내는 항상 보입니다.
- 톡 치기는 주행 화면을 그대로 둡니다. 주행 화면에서 끌면(10px 이상) 방향·기울기는 그대로 둔 채 지도만 손가락을 따라 옮겨 앞길을 봅니다 (평면 지도로 바뀌지 않음).

- 지도 오른쪽 맨 위 버튼: **진행 방향이 위** ↔ **북쪽 고정** 전환 (설정의 "진행 방향이 위로"와 같은 값)
- 한 손가락으로 끌면 지도 이동, 두 손가락으로 오므리면 축소·펼치면 확대 (주행 화면에서는 내 차를 가운데 둔 채 한 단계씩). 손으로 바꾼 배율은 30초 동안 자동 줌이 덮어쓰지 않습니다.
- 지도를 옮기면 아래 가운데 **내 위치로** 버튼이 뜹니다. 누르거나, 손을 떼고 기다리면 다시 내 차를 따라갑니다 (주행 중·길안내 중 5초, 서서 둘러볼 때 15초. 버튼 아래 막대가 줄어드는 것으로 남은 시간 표시).
- 내 차는 GPS(보통 1초에 한 번) 사이를 속도·방향으로 예측해 매 프레임 부드럽게 움직이고, 길안내 중에는 경로(도로) 위에 붙어서 움직입니다.
- 길안내 중 지나온 경로는 지워지고 내 차 앞의 남은 경로만 그려집니다.
- 경로 색: 교통 정보가 없는 길(대개 차가 거의 없는 한산한 길) 파랑, 그리고 다섯 단계(2026-11-14): 원활 초록, 서행 노랑, 지체 주황, 정체 빨강, 심한 정체 검붉은색. 네이버 길찾기 구간 혼잡도(원활·서행·혼잡)를 그 구간 평균 속도로 한 단계 더 나눕니다(고속도로 55·20km/h, 일반 도로 22·8km/h 아래면 한 단계 짙게). 오른쪽 경로 막대도 같은 색입니다. 네이버 길찾기는 주요 도로 구간에만 혼잡도를 주므로 나머지는 파랑입니다.
- 왼쪽 경로 막대는 맨 아래 출발·맨 위 도착으로 고정되어 있고, 내 차 점이 올라가면서 지나온 만큼 색 막대가 줄어듭니다. 재탐색해도 출발점은 그대로입니다.
- 경로에서 30m 넘게 벗어나 3번 연속 확인되면(80m 넘게 벗어나면 2번) **같은 목적지를 '추천'(실시간 최적) 경로로** 다시 탐색합니다. 처음에 '무료 도로'를 골랐으면 다시 찾을 때도 무료 도로로 찾습니다. 간격은 10초부터, 계속 벗어나도 최대 40초. 새 경로에 20초 안에 올라타지 못해도 다시 탐색합니다.
- 처음 경로를 고를 때도 '추천'이 기본으로 선택됩니다(설정 → 경로 옵션에서 바꿀 수 있음).

## 단속 카메라 경고

- 경고 시작 거리(카메라가 있는 도로 기준): 고속도로 3km(음성은 2km에서), 고속화도로(제한 80 이상) 1km, 일반도로 400m.
- **길안내 중에는 안내하는 경로 위의 카메라만** 알리고(경고, 지도 아이콘, '다음 단속' 모두), 잠깐 경로를 벗어나도 다른 길 카메라는 알리지 않습니다. 경로 위 카메라는 남은 경로에서 20m 안(도로명이 같으면 30m 안)에 있고 도로명이 다르지 않은 것입니다. 고속도로 구간에서는 옆·아래 일반도로의 저속(70 이하) 카메라를 뺍니다. 고속도로 구간은 경로 구간 이름이 '고속도로'인 곳과, 이름이 없어도 네이버 안내의 고속도로 진입(50·57·66)부터 출구(51·58·67)까지입니다(2026-11-14: 수도권제1순환고속도로 송파 거여동에서 구간 이름이 빠진 경로로 바로 밑 문정로 어린이보호구역 30 이 떴음. 자동 테스트 S52). '다음 단속' 거리는 경로를 따라 잰 거리입니다.
- 길안내가 없으면 진행 방향 앞, 옆으로 크게 벗어나지 않은 카메라를 알립니다. 굽은 길에서는 최근 주행 궤적이 휜 정도로 앞길을 원호로 예측해서 찾고(직선으로만 보면 굽은 길 앞 카메라를 옆 도로로 오인해 놓침), 지금 달리는 도로와 이름이 같은 카메라는 더 너그럽게 잡습니다.
- '19번 국도', '국도1', '국지도70', '지방도333'처럼 노선 번호만 있는 도로명은 비교하지 않습니다(진짜 카메라를 놓치지 않게). '고속화도로'는 고속도로 규칙에서 뺍니다.
- 반대편 차로 카메라는 뺍니다: 데이터에서 한 방향(상행/하행)만 찍는 카메라가 내 진행 방향 왼쪽으로 8m 넘게 떨어져 있으면 반대편 차로용으로 봅니다(우측통행). 양방향 카메라는 빼지 않습니다.
- 데이터 좌표와 실제 단속 지점이 15m 안팎 다르므로, 카메라를 지나간 뒤에도 30m까지는 경고 카드를 그대로 두었다가 없앱니다(오차 거리는 따로 표시하지 않음). 후면단속 카메라는 60m.
- 과속 중 반복 경고음은 1초에 한 번, 짧게 한 번만 울립니다. 단속 지점을 다 지나면 '띠링' 한 번 울립니다.
- 구간단속: 시작 카메라를 지나면 "구간단속 시작"과 함께 평균 속도 카드가 뜨고, 끝 카메라를 지나면 "구간단속이 끝났습니다"로 닫힙니다. 길안내 중이면 남은 거리를 경로 위 끝 카메라까지의 실제 거리로 보여 줍니다(데이터의 구간 길이는 어림값이거나 비어 있음). 평균이 제한을 넘으면 "남은 구간 ○○ km/h 이하로"를 보여 주고 한 번 음성으로 알립니다. 실제 경로(수도권제1순환고속도로 판교 부근 3.3km 구간)로 자동 테스트(S27)합니다.
- 지도 위 카메라 아이콘은 길안내 중이면 경로 위 카메라만, 길안내가 없으면 내 진행 방향 앞의 카메라만 보여 줍니다(반대편 차로·옆 도로·지나온 카메라는 숨김).
- 어린이·노인 보호구역 카메라는 도로 주의 표지 모양으로 알립니다: 빨간 테두리 노란 삼각 표지, 빨간 띠에 남은 거리, 아래에 '어린이보호'(또는 '노인보호')와 큰 제한속도. 과속하면 빨간 띠가 깜박입니다. 지도 아이콘도 노란 바탕입니다.
- 이동식 카메라는 파란색으로 표시하도록 준비돼 있습니다(카메라 종류 8). 다만 경찰청 공개 데이터에는 고정식만 들어 있어 지금은 이동식 위치가 없습니다.
- **교차로 '신호' 카메라는 신호·과속으로 봅니다.** 경찰청 원본은 교차로 다기능 카메라 대부분을 '신호(2)'로만 올려 둡니다: 신호 전용이 1만 8천여 대인데 99% 넘게 제한속도가 적혀 있고 대부분 2019년 이후 설치입니다. 실제로 가평 계량교·청평 경춘로 카메라들이 과속도 찍는데 '신호'로만 올라 있어 하나도 안 잡혔습니다(2026-11-14 주행). 그래서 `tools/build_cams.py` 가 제한속도가 있는 '신호' 카메라를 신호·과속으로 바꿉니다.
- **넓은 도로**: 카메라가 경로선(도로 가운데)에서 20~40m 떨어져 서 있기도 합니다(올림픽로 36m·한밭대로 34m·경부고속도로 35m). 길안내 중 경로 위 카메라는 20m 안이면 그대로, 20~40m 는 내 도로라고 확인될 때만 인정합니다: 경로 구간 이름이 같거나, 구간 이름을 모르면 근처 경로 바로 위에 같은 도로의 카메라가 있거나, 지금 달리는 도로(역지오코딩) 이름이 같을 때. 실제 대전 경로로 자동 테스트(S38).
- **전국 점검(2026-11-14)**: 서울·부산·대구·광주·대전·제주·인천·수원·청주·전주·강릉, 경부·서울양양 고속도로, 국도 등 실제 네이버 경로 16개(약 480km)를 길안내로 달려, 경로 40m 안에서 내 방향(양방향이거나 오른쪽·가운데)인 카메라 중 경로 구간 이름이 같거나 모르는 것은 모두 잡히고 반대 차로 카메라는 하나도 안 뜨는 것을 확인했습니다. 빠지는 것은 교차하는 다른 도로(이름이 다른 가로 도로)의 카메라뿐입니다. 점검 경로·스크립트는 `test/.audit/`(저장소에 올리지 않음).
- **과속 전용 카메라는 설치장소에 방향(A→B)이 적혀 있으면 한 방향으로 봅니다.** 원본 방향 코드가 '양방향'이어도 실제로는 한쪽만 찍는 경우가 있어(양서면 북한강로 '골용진 입구(용늪삼거리→양평수난구조대)' J2675: 남행에서 반대편인데 떴음, 2026-11-14) 1,571대를 한 방향으로 바꿨습니다. 앱은 한 방향 카메라가 진행 방향 왼쪽 8m 넘게 있으면 반대편으로 보고 뺍니다. 실제 경로로 자동 테스트(S43).
- **교차로 신호·과속 카메라는 반대 방향 등록이 없으면 양방향으로 봅니다.** 원본엔 한 방향만 올라 있어도 실제로는 반대 방향도 찍는 교차로가 많습니다(포회촌·수리재마을입구·청평검문소·소돌마을: 원본엔 '서울→춘천'만 있는데 서울 방향에도 카메라가 있음). 같은 도로 150m 안에 반대 방향 카메라가 따로 등록돼 있지 않으면 양방향으로 바꿉니다(7,572대). 과속 전용 카메라는 구간 중간에서 한쪽만 보는 경우가 많아 그대로 둡니다. 실제 경로(가평 계량교 → 경춘로 → 팔각정삼거리 → 북한강로 28km)로 자동 테스트(S37): 내 방향 9곳은 모두 잡히고 반대 방향 전용 3곳은 빠집니다.
- 제한속도가 없는 진짜 신호 전용 카메라(77대)만 기본으로 알리지 않습니다(설정 → "제한속도 없는 신호 전용 카메라도 알림"). 어린이보호구역 카메라는 항상 알립니다.
- 보호구역 코드가 비어 있어도 설치장소에 '어린이보호구역'·'스쿨존'·'노인보호구역'이 적혀 있으면 보호구역으로 봅니다(457대).
- 신호·과속을 함께 찍는 카메라는 제한속도 표지 위에 작은 가로 신호등 아이콘이 붙습니다(경고 카드, 지도 아이콘, '다음 단속').
- 테슬라 모드에서 보호구역 단속은 단속이 먼저입니다: 맨 위에 보통 과속 단속(제한속도·거리·게이지), 그 밑에 내 속도, 맨 밑에 작은 '어린이 조심'(또는 '어르신 조심') 표지.
- **설치장소 방향('A→B')으로 한 방향 카메라 가르기:** 좌표가 도로 한가운데라 좌우로 못 가르는 한 방향 카메라가 있습니다(2026-11-14: 하남 창우로 J2735 '창우지하차도 지나 250m(하남ic->팔당대교)' 60 이 팔당대교IC → 하남IC 로 갈 때 떴음). 그래서 한 방향 카메라 8,784대는 설치장소의 A·B 를 데이터에 담아 두고(`arrowNames`·`arrows`), 길안내 중 앞뒤 8km 의 안내 문구와 맞춥니다. 'X에서'의 X 는 그 안내 지점(지나온 안내면 뒤, 갈 안내면 앞), ''Y, Z' 방면'은 늘 앞(가는 곳). 뒤에 B 가 있거나 앞에 A 가 있으면 반대 방향이라 알리지 않고, 앞뒤에 다 있거나 없으면 그대로 알립니다. 실제 경로로 자동 테스트(S47): 남행에서 J2735 는 조용하고 같은 길 J0452 '(팔당대교→하남IC)' 50 은 뜨며, 북행에서는 J2735 가 뜹니다. 전국 16개 경로 점검 결과는 그대로(130/149, 반대 방향 0).
- **'구간 시점/종점' 문구:** 구간단속인데 원본의 단속구간위치구분이 비어 있고 설치장소에만 '구간 시점/종점'이 적힌 카메라 29대(울산 아산로, 여수 엑스포대로, 거가대로, 포항 영일만대로, 영덕 동해대로, 안동 경북대로, 세종로, 구리포천고속도로 등)를 구간 시점·종점으로 봅니다(합쳐서 14곳). 원본의 구간단속 지점 1,227건 중 실제 단속 지점은 모두 들어 있습니다(빠진 14건은 주정차 단속 오기재). 자동 테스트 S51.
- **박스형:** 경찰청 원본 4만 4,650건에는 박스형·이동식 카메라가 한 건도 없습니다('박스'는 메가박스 같은 장소 이름뿐). OpenStreetMap 의 국내 단속 카메라도 738개뿐이라 대신 쓸 수 없어, 주행 중 확인한 곳만 직접 넣습니다(U0002 팔당).
- **데이터 보정:** 개별 카메라 보정은 `tools/build_cams.py` 의 `FIXES` 에 관리번호로 적습니다(종류·제한속도·후면단속). 원본을 새로 받아 다시 만들어도 보정은 그대로 들어갑니다.

- **원본에 없는 카메라:** 직접 달려 보고 확인한 카메라는 `tools/build_cams.py` 의 `ADDS` 에 넣습니다. 좌표는 그 방향 차로 쪽 길가에 둡니다(반대 방향에서 왼쪽 8m 넘게 떨어져야 반대편 차로용으로 빠짐).

## 주의 표지

- 다른 내비의 '미끄럼 주의'처럼, 길에 세워진 주의 표지를 **300m 앞부터** 과속방지턱 칸 자리에 표지 그림 + 이름 + 거리로 보여 줍니다(예: '미끄러운 도로 250m'). 표지를 지나친 뒤 150m 동안은 거리 대신 '주의'로 남깁니다(위험은 표지 뒤에 있으므로). 소리는 내지 않습니다.
- 종류(빨간 테두리 노란 삼각 표지, 직접 그린 그림): 미끄러운 도로(126, 상습 결빙 포함) · 낙석(130) · 오르막 경사(116) · 내리막 경사(117) · 노면 고르지 못함(128) · 횡풍(137) · 야생동물(139) · 도로 폭 좁아짐(118) · 철길 건널목(110) · 위험 구간(140, 사고 잦은 곳 포함). 과속방지턱(129)은 `data/bumps.json` 이 따로 있고, 횡단보도·어린이보호·굽은 도로·교차로 표지는 너무 흔해서 뺍니다.
- 길안내 중에는 경로 25m 안의 표지를, 길안내가 없으면 진행 방향 바로 앞 200m 안의 표지를 씁니다. 표지는 도로 오른쪽에 서므로 경로 왼쪽으로 5m 넘게 떨어진 표지는 반대 방향용으로 보고 뺍니다(오르막·내리막이 뒤바뀌지 않게).
- 데이터: 공공데이터포털 '전국도로안전표지표준데이터'(data.go.kr 15028194, 경찰청 소관·지방자치단체 제공, 반기 갱신). 안전표지구분 1(주의표지)만. 지자체마다 '안전표지종별일련번호' 칸에 표지 번호 대신 일련번호를 넣은 곳이 많아 '안전표지설명' 글(예: '미끄러운도로')로 종류를 고릅니다. 같은 종류가 15m 안에 겹치면 하나로.
- 2026-11-14 기준 `data/signs.json`: 오픈API로 받은 53개 기관의 주의표지 25,496건 중 위 10종 2,190곳(위험 851 · 미끄러운 도로 402 · 낙석 251 · 오르막 177 · 내리막 169 · 도로 폭 좁아짐 147 · 노면 75 · 야생동물 46 · 철길 41 · 횡풍 31, 23KB). 자료가 많은 곳: 여주·아산·이천·구미·양주·김해·동해·대전·곡성·포천·인천 남동구·의정부·원주·구리·하남 등.
- 이용 조건: 공공데이터포털 오픈API 이용허락범위 '저작자표시' — 출처는 '공공데이터포털 전국도로안전표지표준데이터(경찰청·각 지방자치단체)'. 앱 설정의 '주의 표지 알림' 문구에도 출처를 적었습니다.
- **한계:** 이 자료는 표지를 등록한 지자체(전국 50여 곳)만 들어 있습니다. 고속도로·대부분의 국도, 자료를 내지 않은 시·군에서는 표지가 있어도 알리지 못합니다.
- 만들기: 그리드 CSV 다운로드는 5만 행에서 잘리므로(27개 지자체까지만) 전체는 오픈API로 받습니다(활용신청 자동승인, 개발계정 하루 1만 회).

  ```
  set DATA_GO_KR_KEY=<공공데이터포털 일반 인증키(Decoding)>
  py -I tools/fetch_signs.py %TEMP%\signs-api.json
  py -I tools/build_signs.py %TEMP%\signs-api.json data/signs.json
  ```

  키는 저장소에 넣지 않습니다. CSV 로도 됩니다: `py -I tools/build_signs.py 전국도로안전표지표준데이터.csv data/signs.json`.
- 설정 → '주의 표지 알림'으로 끌 수 있습니다. 자동 테스트 S55.

- 진행 방향 위: 문서에 없는 `map.setRotation(진행 방향)`·`map.setTilt(40)` 로 지도 자체를 돌리고 기울인다. 글자·가게 아이콘은 똑바로 선다. 캔버스는 화면 아래로 길게(가운데 = 화면 70% 높이) 두어 차가 화면 아래쪽에 온다. 회전은 매 프레임 조금씩(0.3초 시상수) 따라간다.
- 멈춰도 북쪽 위로 바꾸지 않는다(글자가 똑바로라 필요 없음). 지도를 끌면 지도 라이브러리가 돌린 지도를 그대로 끌고, 앱은 '내 위치로'·5초 복귀만 맡는다.
- 밤: 위 '야간 지도'. 다크 지도 종류로 바꾸면 스타일이 통째로 바뀌므로 실시간 교통 선을 다시 붙이고, 다크용 교통 선(`CTT/다크/*`)은 앱이 직접 켠다.
- 설정 → '벡터 지도'를 끄면 예전 그림(래스터) 지도 + CSS 회전. WebGL 이 없거나 GL 모듈이 8초 안에 안 오거나 주행 중 WebGL 이 끊기면(context lost) 저절로 그림 지도로.

## 배포 규칙

- `app.js`를 바꾸면 세 곳의 버전을 함께 올립니다: `app.js`의 `APP_VERSION`, `index.html`의 `app.js?v=`, `version.json`. 자동 테스트(S19)가 세 값이 같은지 확인합니다.
- 그냥 링크(`https://bravecheeze.github.io/tesla-naver-cluster/`)로 들어와도 최신 버전이 뜹니다. 페이지를 열 때 `version.json`을 캐시 없이 확인해서, 지금보다 새 버전이면 한 번만 새로고침합니다. 차가 잠들었다 깨어났거나 화면이 5분 넘게 가려졌다 다시 보일 때도 확인합니다.
- 운전 중에는 절대 새로고침하지 않습니다(길안내 중, 시속 3km 이상, 데모 중에는 건너뜀). 같은 창에서 같은 버전으로는 한 번만 시도해서 새로고침이 반복되지 않습니다.
- 주차 중 켜 둔 화면도 알아서 바뀝니다: 2분 넘게 서 있고, 2분 넘게 화면을 만지지 않았고, 길안내·검색·설정·경로 고르기 화면이 열려 있지 않으면 10분마다 새 버전을 확인합니다.
- 카메라 데이터(`data/cameras.json`)도 앱 버전을 붙여 받으므로 새 버전과 함께 바로 바뀝니다.
- **새 버전으로 옮겨 갈 때는 주소에 `?v=새 버전`을 붙여 이동합니다.** 그냥 새로고침하면 브라우저·CDN 에 저장된 예전 `index.html`(GitHub Pages 는 10분 캐시)이 다시 뜰 수 있습니다(2026-11-14 차에서 새로고침했는데 예전 버전). 바뀐 직후 "새 버전으로 바뀌었어요" 알림이 뜨고, 하단 위치 띠를 누르면 버튼 위에 지금 버전이 보입니다.
- **운전·길안내 중에는 바꾸지 않습니다.** 대신 2분마다 새 버전이 있는지 보기만 하고(version.json), 있으면 오른쪽 위 날씨 밑에 작은 파란 **'업데이트'** 버튼이 늘 보입니다(하단 위치 띠를 눌렀을 때도 **'새 버전'** 버튼). 누르면 새 버전으로 바뀌고, 길안내 중이었으면 목적지·경유지·경로 옵션을 기억했다가 첫 위치를 받는 대로 경로 카드 없이 이어서 안내합니다(15분 안).
- 테슬라 브라우저는 앱을 다시 열어도 열려 있던 화면을 그대로 보여 줄 뿐 새로 불러오지 않습니다(2026-11-14 접속 기록으로 확인). 그래서 위 버튼이 필요합니다.

## 운영 모니터링

- 페이지는 접속 시각과 오류(스크립트 오류, 지도 인증 실패, 경로 실패, GPS 권한 거부 등)를 길안내 서버 `/event`로 보냅니다. 위치는 보내지 않습니다. 7일 보관.
- 기록 키는 최신이 맨 앞에 오도록 뒤집은 시각(`evr:`)으로 저장합니다. 예전 형식(`evt:`, 시각 오름차순)은 KV 목록이 앞에서 1000개만 주는 탓에 기록이 1000개를 넘자 새 기록이 안 보였습니다(2026-11-14). 예전 기록은 `/events?legacy=1` 로 볼 수 있고 7일 뒤 사라집니다.
- 새 버전을 올려도 이미 열려 있는 화면은 새로고침 전까지 그대로 동작합니다(자동 새로고침 없음). 서버는 예전 페이지와 호환되게만 바꿉니다.

## 4. 진단 모드 (실차 측정)

설정 → **진단 모드 켜기**를 누르면 지도 왼쪽 아래에 다음 값이 실시간으로 나옵니다.

- GPS 갱신 주기(Hz, 간격 ms)
- 위치 지연: 위치가 측정된 시각부터 페이지가 받은 시각까지
- 정확도(±m)
- 브라우저가 속도·방향 값을 직접 주는 비율
- 처리 시간과 화면 반영 시간(ms)

주행하는 동안 원본 위치 기록이 쌓입니다. 주행 후 **기록 업로드**를 누르면 기록 번호가 나오니, 그 번호를 알려 주면 분석해서 보정합니다. 여러 장소(도심, 고가도로, 터널 앞뒤, 고속도로)에서 한 번씩 기록하면 가장 좋습니다.

## 한계

- 속도는 GPS 기준이라 차 속도계와 조금 다를 수 있고, 터널에서는 끊깁니다. 차량 데이터는 웹페이지에서 읽을 수 없습니다.
- 지도 회전은 화면 자체를 돌리는 방식이라 지도 글자도 함께 돌아갑니다(네이버 웹 지도는 일반 지도에서 회전을 지원하지 않음). 그래서 3초 넘게 멈추면 북쪽 위 지도로 바꿔 가게 이름을 똑바로 보여 주고, 다시 시속 8km를 넘으면 진행 방향 위로 돌아옵니다(설정 → "멈추면 북쪽이 위로").
- 차선 안내와 교차로 실사 이미지는 네이버 길찾기 API가 데이터를 주지 않아 넣지 못했습니다.
- 단속 카메라는 고정식만 들어 있고(이동식 제외), 공공데이터 갱신 주기는 반기입니다.
- 테슬라 카메라 영상은 브라우저에서 접근할 방법이 없습니다.
